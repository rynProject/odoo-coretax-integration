Coretax Integration (AksaTax)

Kirim e-Faktur Keluaran & Bukti Potong PPh dari Odoo ke DJP (Coretax) lewat AksaTax

Faktur pelanggan di Odoo dikirim ke DJP melalui Public API AksaTax. Hasilnya (status DJP, Nomor Faktur Pajak, kode persetujuan, dan alasan penolakan) kembali ke Odoo secara otomatis, tanpa ekspor-impor file.

Alur kerja

1. Odoo

Faktur pelanggan ber-PPN yang sudah diposting diperiksa dulu (NPWP/NIK, kode transaksi, kode barang/jasa, mata uang, kelompok pajak, tanggal), lalu dikirim.

2. AksaTax

e-Faktur dibuat sebagai draft di AksaTax, lalu langsung dikirim ke DJP atau disimpan dulu untuk disetujui di AksaTax.

3. DJP → Odoo

Odoo mengambil hasil dari AksaTax setiap 5 menit, atau langsung lewat webhook bertanda tangan HMAC. Status dan nomor faktur pajak tampil di faktur.

Fitur

Kirim e-Faktur

Dari tombol Kirim e-Faktur di faktur pelanggan, per baris, atau banyak sekaligus dari daftar Siap dikirim. Bisa juga otomatis saat faktur diposting.

Pemeriksaan sebelum kirim

Setiap faktur diperiksa sebelum dikirim, dan pesan kesalahannya ditulis dalam bahasa yang mudah dipahami tim keuangan.

Perlu tindakan

e-Faktur yang ditolak DJP atau gagal dikirim dikumpulkan di satu daftar, lengkap dengan alasan dan tombol Buat ulang e-Faktur. Penanggung jawab faktur menerima aktivitas "Perbaiki e-Faktur".

Lawan transaksi

Pelanggan dan vendor dicocokkan dengan Lawan Transaksi AksaTax lewat NPWP. Yang belum terdaftar bisa didaftarkan langsung dari Odoo, satu per satu atau massal.

Pemetaan field

NPWP, NIK, paspor, NITKU/TKU, nama, alamat, dan email diambil dari field kontak standar Odoo, dan bisa diganti dengan field kustom atau Studio.

Kesiapan data

Menampilkan produk yang masih berkode umum 000000, satuan tanpa kode Coretax, dan pelanggan tanpa NPWP/NIK, dan semuanya bisa diperbaiki langsung dari daftarnya.

Bukti Potong PPh

Dibuat dari tagihan vendor dengan tombol Buat Bukti Potong, lalu dikirim ke AksaTax sebagai draft untuk ditandatangani di sana.

Ringkasan & riwayat

Satu layar ringkasan (siap dikirim, diproses, disetujui, perlu tindakan) dan Riwayat Sinkronisasi 90 hari lengkap dengan ID Permintaan. API key tidak pernah ikut dicatat.

Angka sama dengan XML Coretax

Data baris disusun dengan penyusun data bawaan Odoo (l10n_id_efaktur_coretax), jadi angkanya sama dengan XML Coretax resmi.

Aman dari dokumen ganda

Setiap pengiriman memakai Idempotency-Key per faktur dan versi. Faktur yang e-Faktur-nya sedang diproses atau sudah disetujui tidak bisa dibatalkan di Odoo begitu saja.

Syarat

  • Odoo 19 dengan modul account dan l10n_id_efaktur_coretax (bawaan Odoo, ikut terpasang otomatis).
  • Akun AksaTax paket Business atau lebih tinggi, karena paket Starter tidak mencakup Public API.
  • API key AksaTax dari Owner/Admin Pajak dengan izin faktur:baca, faktur:tulis, faktur:kirim, bupot:*, dan status:baca.
  • Satu API key mewakili satu NPWP, jadi tiap perusahaan di Odoo butuh API key sendiri.

Mulai dalam 5 langkah

  1. Pasang modul Coretax Integration (AksaTax).
  2. Buka Coretax › Pengaturan › Koneksi AksaTax, isi alamat dan API key, lalu klik Uji koneksi.
  3. Pilih cara kirim: manual dari faktur atau otomatis saat diposting. Webhook bersifat opsional.
  4. Klik Cocokkan semua pelanggan.
  5. Pasang Kode Barang/Jasa Coretax di produk.

Batasan saat ini

Hal berikut belum tersedia di Public API AksaTax, jadi dilakukan langsung di aplikasi AksaTax (tombol Buka di AksaTax membuka dokumennya):

  • mengubah Lawan Transaksi yang sudah ada;
  • membatalkan atau mengganti e-Faktur, nota retur, dan unduh PDF faktur pajak;
  • penandatanganan dan pengiriman Bukti Potong ke DJP;
  • Faktur Masukan dan SPT;
  • kode transaksi 07/08 dan 10.
